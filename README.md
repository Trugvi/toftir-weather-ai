# Toftir Weather AI v5

This version adds wind direction arrows (for example `↙ SW (225°)`) in the combined hourly forecast, summary metric, and individual model tables. It also retains 24-hour time formatting, daily wind roses, temperature in °C, rainfall, and freezing-risk screening.

## Run

```bat
py -3.13 -m pip install -r requirements.txt
py -3.13 -m streamlit run app.py
```
